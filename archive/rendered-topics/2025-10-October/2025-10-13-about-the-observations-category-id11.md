# About the Observations category

admin | 2025-10-13 17:04:06 UTC | #1

A place for sharing raw and unfinished Bitcoin network observations with others.

Feel free to post network observations here. Ideally, include time-of-observation, images, links, ...

 Examples could be:

- A spike in new Bitcoin nodes coming online at the same with the same version.
- An anomaly in the Lightning network gossip rate
- ...
