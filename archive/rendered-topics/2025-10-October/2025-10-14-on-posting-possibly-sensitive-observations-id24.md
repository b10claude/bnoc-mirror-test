# On posting possibly sensitive observations

admin | 2025-10-16 06:23:30 UTC | #1

In some cases, a Bitcoin network observation can contain sensitive information. For example, you notice that your node is getting DoS'ed and you end up identifying the cause for this.

Don't post observations like these publicly. If there's need to discuss a sensitive topic here, a private group can be created ad-hoc and trusted members can be invited. 

At some later point, the post can then be made public.
