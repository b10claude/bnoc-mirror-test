# Why not use delvingbitcoin.org for BNOC?

admin | 2025-10-14 10:22:57 UTC | #1

Why set up an extra forum when there is delvingbitcoin.org already?

[bnoc.xyz](https://bnoc.xyz) is intended for raw and unfinished Network observations and discussions there of. A common pattern is:

1. Observe something
2. Maybe look into it if it seems worthwhile
3. Maybe react to it if there's something to do about it

Many of these observations don't result in an interesting outcome and probably aren't interesting to a large part of the delvingbitcoin.org readers.

If there's an interesting outcome, a polished posts with a e.g. clear call-to-action can still be posted to delvingbitcoin.org.
